### 1.1 🔴 批改自查四条铁律（阶段20 踩坑后立规）

**血泪教训**：初版把第 8、9 题的**空括号**看成手写字母 C，
据此判"英语第 8 题答错"并写进错题库。二次逐像素复核才发现是空的。
**猜出来的错题比漏掉的错题更有害** —— 它会污染错题库、误导后续复习、还可能冤枉孩子。

| # | 铁律 | 具体做法 |
|:--:|---|---|
| 1 | **括号里的字必须放大看清楚** | PIL 裁切 + **≥6 倍 LANCZOS** + `ImageOps.autocontrast(gray, cutoff=2)` 提对比。**小图看不清就绝不填答案** |
| 2 | **答案要交叉验证** | 同一份卷子至少两处独立确认；**与前后题答案模式比对**（发现"全是 C"要警惕误读） |
| 3 | **拿不准就标"待确认"，不要猜** | 宁可写"看不清，待人工确认"，也不能猜一个字母入库 |
| 4 | **判错前先质疑题目本身** | 尤其语音题：**先看划线画在哪**。题面与解析对不上时，先改题，别记孩子的错 |

**放大代码模板**（`grade_submission` 前必做）：
```python
from PIL import Image, ImageOps, ImageEnhance
im = Image.open(src).convert("RGB"); w, h = im.size
c = im.crop((int(w*0.78), int(h*0.742), int(w*0.98), int(h*0.775))) # 括号那一小块
c = c.resize((c.width*10, c.height*10), Image.LANCZOS) # 必须 ≥6 倍
c = ImageOps.autocontrast(c.convert("L"), cutoff=2) # 提对比，突出墨迹
c.save("crop_zoom.png")
```

> ⚠️ **只在低倍率图上"看着像 C"是不成立的**。印刷括号 + 手写笔迹在小图上极易混淆，
> 必须放大到能区分「印刷体的括号」与「手写字母」。

| 5 | **判错前先读全题干规则；密集手写不得凭局部印象补写内容** | 阶段31 期中订正：初判没读到第 9(1) 题「任选两句作答；如三句皆答按前两句判分」，把只答 ②③ 且全对误判成「③白写、半对」并入库；又把作文内容凭印象写成「父亲护我躲蛇、送我上学」，实际是「油菜花田割伤、雪山递气瓶、初中补课」。**夸克 Agent CLI OCR 复核题面 + 全文后，错题 1441 作废、1448 订正、A9-1 半对→对**。做法：①判分前用 `general-ocr` 把题干全文读一遍，圈出计分规则；②长文手写必须整篇转录后再归因，不许用「大概写了…」入库；③已入库的误判要**作废归档 + 删分类映射 + 改计分点 + 留订正依据**，不要悄悄删掉 |

## 二、⚠️ 两个脚本坑（已修，勿重犯）

### 坑 1：`errors` 表有三个 NOT NULL 且无默认值的列

```
sqlite3.IntegrityError: NOT NULL constraint failed: errors.chapter
```

`chapter` / `tags` / `resolved` 三列必须显式给值（`resolved` 是**计数列不是布尔**，写 `0`；
`study_round` 是**文本列不是整数**，写 `"1"`）。插入语句已修正，见 `grade_submission.py`。

### 坑 2：JUDGE（简答题）字面覆盖率会误判

孩子用自己的话写、标���答案是术语，`hit_ratio` 字面比对必然偏低 → 病句修改题被判 0 分。

**修正后的兜底逻辑**（`grade_q` 里）：
- 先按要点覆盖率判（≥0.8 对 / ≥0.4 半对）
- 不达标时走**软匹配**：命中**语病类型名**（7 型枚举）+ **引号内的原文操作**
  + **"删/去掉/改为 + xxx"动作词** → 至少命中 1 项且答案长度 ≥12 → 判「半对·待人工确认」
- 仍不达标才判错

> **原则：语文主观题失分诊断早已定性为「提取失败」，不能用字面重合度判卷。**

## 三、批改中暴露的共性问题（示例已脱敏）

本公开版不含真实成绩、逐题作答明细与教师反馈原文。以下只保留可复用的结论：

**最典型的失分动作是「跳步」** —— 找到一个线索就下判断，不做全量逐项确认。
典型表现：漏写判断行、干净的句子不写「没有语病」、改病句只写删什么不写改后完整句、
选择题不填字母不涂卡、语音题不横比四个选项。

固化为五条「逐项写」规则（详见 `references/lecture-pipeline.md` §5A）：

1. 程序框图必须逐行写判断，含「不成立」分支
2. 干净句也要明确写「没有语病」
3. 病句修改必须写出改后的完整句子
4. 语音题先写四行音标再选
5. 选择题填字母 + 涂 ○，两者都要

**教训**：格式门禁全绿 ≠ 内容干净；方法有效与否要看逐项确认这个动作有没有发生。

## 四、批改反馈的书写规范

1. **结论前置**：第一句就说"最重要的一件事"（本次是"答案全对，但过程有 4 处跳步"）
2. **答案对 ≠ 批改完**：必须看手写过程，找出跳过的步骤
3. **区分「对的能力」和「对的结果」**：第 2 题跑对第二轮是能力，第 8 题靠排除法是运气
4. **跨题找共因**：本次 4 处跳步归到同一根因，这才是可干预的靶点
5. **给具体动作，不给"下次注意"**：要写成"③ 句补写『没有语病（本题正确项）』"这种可勾选的
6. **已验证有效的设计要写进技能**，防止后续迭代改回去

## 批改判分的两处致命误判（阶段21 实测，必须记）

Day2 首次判分给出 **对6/半对1/错3、65 分**，但对着照片人工核对后发现
**3 处是冤枉**，真实是 **对8/半对1/错1、85 分**。

> **判错比漏判更有害**：污染错题库、误导复习、冤枉孩子。
> 判分器出结果后，**必须对着原卷人工复核一遍再入库**。

### 误判一：分数与小数不等价

标准答案 `117/4`（fr 标记），孩子写 `29.25` —— **两者相等**，
但判分器剥标签得 `1174`、数值提取得 `1174 ≠ 29.25` → 判错。

**修法**：`_frac_value()` 专门解析分数——
- 认 fr 标记的 `nu`/`de` 两个 span，分子÷分母
- 认 `a/b` 形式
- 认纯小数
三者都转成 float 再比（容差 1e-6）。

### 误判二：短要点被过滤掉

`points()` 原阈值 `len(norm(p)) >= 6` 字，把 **「拟人」「对比」「托物言志」
这类核心术语整个丢掉**。于是孩子答了「拟人」反而不计入命中，
被判 `0/2 要点` 错。

**修法**：阈值降到 **≥2 字**（1 字多为标点噪声）。

### 误判三：同义不同字（语文主观题的通病）

标准「思乡怀亲」，孩子写「思念故乡」；标准「托雁传书」，孩子写「托大雁捎信」
—— 意思完全对，字面重合只有 1–2 个字。

**修法**：加 `SYN_GROUPS` 同义词组表（思乡/托雁/拟人/时序交替/新必替旧…），
命中同一组即算该要点命中。

> 这条印证了早已定性的原则：**语文主观题不能用字面重合度判卷**。
> 孩子用自己的话写、标答是术语，字面覆盖率必然偏低。

### 必须单独记的一类：「提示后改对」

Day2 第2题原两空都填 `<`，家长提示后改成 `B（前<、后>）`。
判分算「对」，但**改对 ≠ 会了**：

- 他知道「两个负数相加为负」（前空对）
- 没推出「a > b ⇒ a − b > 0」（后空错）

→ 单独入库一条 `error_type = 概念不清（提示后改对）`、`status = 未掌握`，
`error_pattern` 写明断点：「减法结果的正负由两个数大小决定，这一步是断的」。
**否则下周还会错在同一处。**

## DSL 出题的两个坑（阶段21 新增补弱题时踩到）

1. **符号要写裸的 `<` `>`，不要写 `&lt;` `&gt;`**
   渲染层 `rich()` 会先 `esc()` 转义，写 `&gt;` 会变成 `&amp;gt;`，
   页面上显示成字面量 `&gt;`。实测讲义校验报「选项含裸实体」。
2. **题干里不要引用「第 N 天第 M 题」**
   分天解析器用 `第 N 天` 切分，写「对位第 2 天第 2 题」会被当成
   **第2天的起点**，导致 Day3 整段被归到 Day2、题号对齐全线崩。
   改用「对位昨日第 2 题」这类不歧义表述。
