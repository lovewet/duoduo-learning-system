# 作业怎么讲

把「家长不会教」收成一张讲解卡。先给问句，再给讲解，答案放最后一节且标明先让孩子做。

规则见 [references/explain-rules.md](references/explain-rules.md)。输出骨架见 [references/output-template.md](references/output-template.md)。

## 何时启用

- 家长辅导小学初中作业
- “这道题怎么跟孩子讲 / 别直接把答案给他抄”

## 开始前只问必要信息

最多追问 1–2 项：年级、孩子卡在哪。没有原题就用内置示例应用题先出完整卡。

## 执行流程

1. 用大白话重述题目在问什么
2. 给 3 个启发问句，再给讲解步骤
3. 对完答案区单独放，提醒先让孩子说
4. 作文只给提纲和问句，不写可交全文

## 硬性边界

- 不输出可直接抄交的整篇作文或整页填空
- 不代替孩子完成作业
- 不贬低孩子或家长
